# Web/app học tập — Khoa học tự nhiên 7, Bài 39

**Bài 39: Sinh sản vô tính ở sinh vật**
Môn Khoa học tự nhiên 7 — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống (Chương X: Sinh sản ở sinh vật).

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng gồm:
1. Diễn biến 4 hình thức sinh sản vô tính theo từng bước (3 bước mỗi hình thức), hình minh họa SVG thay đổi theo từng bước: giâm cành, nảy chồi (thủy tức), phân mảnh (sao biển), nuôi cấy tế bào và mô.
2. Trò chơi ghép nối 6 cặp: sinh vật — hình thức sinh sản vô tính (dâu tây, lá bỏng, dương xỉ, thủy tức, sao biển, ong mật).

Khóa đáp án trắc nghiệm: 1A 2A 3A 4A 5B 6A 7B 8A 9A 10D.

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong thư mục

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_KHTN7_Bai39.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — mã Apps Script ghi điểm vào Google Sheets (tab KetQua).
- `assets-flow/` — 3 ảnh nền (đăng nhập, nền chính, hero) + logo giáo viên.
